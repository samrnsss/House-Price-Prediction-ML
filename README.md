# House Price Prediction using Linear Regression

## About the Project

This project focuses on predicting house prices using Supervised Machine Learning. It uses Linear Regression to understand the relationship between different housing features and their selling prices.

This is my first Machine Learning project, developed as part of my learning journey in Python and Machine Learning.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Workflow

1. Dataset Loading
2. Exploratory Data Analysis (EDA)
3. Data Preprocessing
4. Handling Missing Values
5. One-Hot Encoding
6. Train-Test Split
7. Linear Regression Model Training
8. Model Prediction
9. Model Evaluation
10. Feature Scaling
